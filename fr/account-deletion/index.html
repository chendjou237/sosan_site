Guide pour la suppression d’un compte sur l’application SOSAN

Comment supprimer votre compte SOSAN depuis l’application, étape par étape. Les comptes médecins et hôpitaux suivent une procédure distincte, avec une suspension préalable de sept jours.

GUIDE POUR LES UTILISATEUR

Étape 1Ouvrir l’application

Localisez l’application SOSAN sur votre écran d’accueil ou dans le menu de votre téléphone.

Appuyez sur l’icône de l’application SOSAN pour l’ouvrir.

Étape 2Accéder au profil de votre compte

Une fois dans l’application, allez dans l’onglet Mon profil, qui se trouve sur la barre de navigation.

Étape 3Trouver l’option de suppression de compte

Dans onglet Mon profil, recherchez l’option intitulée Supprimer le compte.

Étape 4Confirmer votre identité

Pour des raisons de sécurité, vous devez confirmer votre identité avant de supprimer votre compte. Cela inclure :

  • Saisir votre mot de passe.
  • Confirmer votre adresse électronique ou numéro de téléphone.

Étape 5Supprimer le compte

Une fois votre identité confirmée, il sera possible pour vous de Supprimer votre compte.

  • Lisez attentivement les informations fournies concernant la suppression de votre compte.
  • Il vous sera demandé de fournir une raison pour la suppression de votre compte (votre réponse est facultative)
  • Si vous êtes sûr de vouloir supprimer votre compte, cliquez sur Confirmer.

Étape 6Confirmation de la suppression

Après avoir confirmé la suppression, vous devriez recevoir un message indiquant que votre compte a été supprimé avec succès.

Vous pouvez également recevoir un courriel de confirmation.

GUIDE POUR LES MEDECINS ET HÔPITAUX

Pour les utilisateurs possédants un compte de type médecin ou hôpital, la suppression de leur compte ne peut se faire directement, car ils doivent dans un premier temps suspendre leurs services pour une durée de sept (07) jours avant d’avoir la possibilité de supprimer définitivement leurs comptes.

Étape 1Ouvrir l’application

Localisez l’application SOSAN sur votre écran d’accueil ou dans le menu de votre téléphone.

Appuyez sur l’icône de l’application SOSAN pour l’ouvrir.

Étape 2Accéder au profil de votre compte

Une fois dans l’application, allez dans l’onglet Mon profil, qui se trouve sur la barre de navigation.

Étape 3Trouver l’option suspendre mon compte

Dans onglet Mon profil, recherchez l’option intitulée suspendre mon compte.

Étape 4Confirmer votre identité

Pour des raisons de sécurité, vous devez confirmer votre identité avant de suspendre votre compte. Cela inclure :

  • Saisir votre mot de passe.
  • Confirmer votre adresse électronique ou numéro de téléphone.

Étape 5Supprimer le compte

Une fois votre identité confirmée, votre compte sera suspendu pour une période de sept (07) jours.

Après ce délai de sept jours, il vous sera possible de supprimer votre compte.

  • Lisez attentivement les informations fournies concernant la suppression de votre compte.
  • Il vous sera demandé de fournir une raison pour la suppression de votre compte (votre réponse est facultative)
  • Si vous êtes sûr de vouloir supprimer votre compte, cliquez sur Confirmer.

Étape 6Confirmation de la suppression

Après avoir confirmé la suppression, vous devriez recevoir un message indiquant que votre compte a été supprimé avec succès.

Vous pouvez également recevoir un courriel de confirmation.
